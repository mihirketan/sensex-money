The gap

Everyone rebuilds the same messy ledger. No one keeps the original pages.

Screeners, terminals, and research platforms all pull from the same exchange bhavcopy files and restate them into today's figures. What gets thrown away in that process is the record of what the market actually knew, when it knew it.

Point-in-time fundamentalsdata, not screens
Financials as originally filed, before later restatement — so a backtest from 2019 uses what a 2019 investor actually saw, not a 2026 revision. largely absent from retail platforms today
Survivorship-inclusive returnscorporate actions
Delisted, acquired, and bankrupt companies stay in the dataset. A universe that only contains today's winners isn't history — it's a highlight reel.
Permanent entity identitycorporate graph
Every ticker, name change, merger, and demerger resolved to one identity, so "what was this security actually representing on this date" has a real answer.
Data confidence, shownprovenance
Every figure carries its own label — verified estimated unconfirmed — instead of presenting inference as fact.
